## 2025-05-14 - Unified and Accessible Empty States
**Learning:** In SwiftUI apps with multiple list-based views (Search, History, Cloud), users often encounter empty states either because no data exists or because a search filter returned no results. Standardizing these states into a single reusable component (`EmptyInstructionView`) that dynamically adapts its icon and text based on the `isSearching` state significantly improves clarity and visual cohesion.
**Action:** Always check the `isSearching` environment or state variable when displaying empty states. Use 'magnifyingglass' for empty search results and a context-specific icon (e.g., 'clock.arrow.circlepath' for history) for naturally empty data. Group title and message using `.accessibilityElement(children: .combine)` to improve VoiceOver efficiency.

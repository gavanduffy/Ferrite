## 2026-02-16 - Enhancing Empty States Accessibility & Dynamic Type
**Learning:** Grouping title and message text in SwiftUI empty states using `.accessibilityElement(children: .combine)` provides a much cleaner VoiceOver experience, reading the entire context in one swipe. Decorative icons should always be hidden using `.accessibilityHidden(true)` to avoid redundant SF Symbol name reads. Additionally, using semantic fonts (e.g., `DesignTokens.Typography.scaled(...)`) ensures the UI scales correctly for users with larger text settings, which is a key requirement for iOS accessibility.
**Action:** Always apply accessibility grouping to empty instruction views and similar informational groupings. Use semantic fonts instead of fixed sizes for all text elements to support Dynamic Type. Use context-specific SF Symbols to provide immediate visual reinforcement of the state.
